Straighten Punctuation

Convert curly quotes, dashes, and ellipses to straight equivalents. Links and formatting are preserved.

Input

Output

Paste rich text (e.g. from a web page or document) and the tool reads its HTML so links and formatting survive. Typing or pasting plain text works too. Copy text to keep only the content, or copy HTML to keep the markup with straightened punctuation.
